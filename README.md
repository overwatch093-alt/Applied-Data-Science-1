# Applied Data Science 1 (7FTC2004)
This repository stores practical exercises, lab materials, and coursework for the **Applied Data Science 1** module.
## Lesson 1 Contents
- `ADS1_Tutorial_1_Python_revision_for_Data_Science.ipynb`: Core Python syntax, functions, and PEP 8 guidelines.
- `ADS1_Tutorial_2 Github_Introduction.ipynb`: Git and GitHub version control setup.
- `ADS1_Tutorial_3_Matplotlib_Worksheet1.ipynb`: 10 practical data visualization exercises with Matplotlib and Pandas.
- `ADS1_Tutorial_4_Relational_Graphs.ipynb`: Visualizing hyperbolic functions, parametric curves, and scatter plots.
